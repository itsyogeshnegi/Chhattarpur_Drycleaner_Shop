# Project Workspace Rules — AL-HARAM Drycleaner's Website

## Always Keep `README.md` Up to Date
Whenever you add, modify, or remove code, API routes, Mongoose models, pages, components, or configuration in this repository:

1. Update any affected section in `README.md` (e.g., Executive Summary, How Everything Works, Project Structure, Data Models, or Environment Variables) so the documentation always reflects the actual codebase accurately.
2. Prepend a concise, dated bullet point under the `## Change Log` section of `README.md` describing what changed and why.
3. Verify any file paths, API endpoints, and symbol names mentioned in `README.md` match the actual repository files.
